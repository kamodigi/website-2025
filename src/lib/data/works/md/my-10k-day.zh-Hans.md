## 项目背景

做这个网站的契机，是和朋友聊起了“出生后的第 1 万天”。大家都会庆祝自己的生日，但我觉得出生后刚好第 1 万天，也是人生中的一个重要节点。1 万天大约相当于 27 年，对很多人来说，这正好是开始步入社会、做出人生重要选择的时期。

于是我想做一个网站，能够在考虑闰年等因素的前提下准确算出这个特别的日子，同时也能借此回顾自己的人生。

## 技术选型

### 选择 SvelteKit 的理由

采用 SvelteKit，很大程度上是因为这是我个人喜欢的框架。原因在于，Svelte 的设计就像是 HTML 和 CSS 的扩展。我也喜欢 React，它全部用 JS 完成，这是它的优点；但 Svelte 的写法感觉像是 HTML 的自然延伸，写起来很舒服。

另外，Svelte 编译后会变成没有额外开销的 HTML、CSS 和 JavaScript，这也是我选择它的理由。React 和 Vue 需要运行时，我认为对小型 Web 应用来说过于繁重。此外，Svelte 使用 JavaScript 库时不需要包装层，这一点也很有吸引力。

### 使用 Paraglide JS 实现多语言

这个网站从一开始就打算支持多语言，所以我选择了轻量的 Paraglide JS。它的 API 简单易用，与 SvelteKit 的集成也很顺畅。

### 没有采用 TailwindCSS 的理由

这次没有采用 TailwindCSS。我本来就对 Tailwind 持怀疑态度。把样式写在类名里，偏离了语义分离的原则。另外，如果要用预设之外的值，就需要写 JIT（Just-In-Time）的语法；既然如此，我觉得直接写 CSS 就好了。

而且近年来可以借助生成式 AI，不使用特殊语法也能轻松写出原生 CSS。我感觉这一变化大大降低了传统 CSS 编写的门槛。

## 实现细节

### 日期计算逻辑

第 1 万天的计算逻辑，我决定使用 API 简单明了的 `luxon` 库。Luxon 能够准确处理闰年和时区，帮我们消化了日期操作的复杂性。

### UI/UX 上的用心之处

在 UI/UX 方面特别下功夫的，是让链接在分享时能够显示 OGP（Open Graph Protocol）。我想，如果用户能轻松分享自己的“1 万天生日”，会是一种有趣的体验。在社交媒体上分享时显示一张美观的卡片，也希望能让更多人知道这个网站。

### 计划实现的功能

“回顾人生”功能计划在今后实现。我希望在出生日、第 1000 天、第 5000 天等节点，显示当时世界上发生的事件，让用户把自己的人生和世界历史叠在一起回顾。

## 部署与基础设施

### Coolify 与日本国内基础设施的选择

部署选择 Coolify，是因为我最近自己租了服务器并在上面运行 Coolify。Vercel 也是很有吸引力的部署平台，但我特意选择 Coolify，是因为可以使用日本国内的基础设施。

日本的数字贸易逆差在不断扩大，作为 IT 从业者，这是我关心的社会问题。我自己能做的，只是借助开源软件尝试使用日本国内的基础设施；但如果这种做法能推广开来，我认为可以成为应对日本数字贸易逆差的一种对策。这虽然只是个人的一个小选择，但我把它看作履行技术人员社会责任的一种方式。

## 开发中遇到的困难

开发中遇到的困难主要在设计和 UI/UX 方面。我没有学过设计，所以一边寻找可以参考的网站设计，一边摸索着推进。当然，生成式 AI 也帮了很大的忙。

比起技术实现，我更深刻地体会到，做出既好用又美观的界面有多难。设计中有很多感性的部分，也没有唯一的正确答案，所以一直在不断试错。

## 今后的展望

我想继续探索，这个网站能否创造出比单纯显示“1 万天生日”更多的价值。思考什么样的体验会让用户觉得有趣，然后实现它——我想不断重复这样的循环。

具体来说，除了实现前面提到的“回顾人生”功能，我还在考虑用户之间互相发送消息的功能、纪念日提醒功能等。我希望通过这个项目，不仅提升技术能力，也锻炼设计用户体验的能力。
